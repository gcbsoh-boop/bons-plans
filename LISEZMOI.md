# Bons plans
1. Double-cliquez sur « Ouvrir les bons plans.bat ».
2. Attendez quelques secondes : la page s'ouvre toute seule.
3. Tapez un mot dans la case, ou cliquez sur une catégorie.
4. Cliquez sur une offre pour l'ouvrir. Pour mettre à jour, double-cliquez à nouveau.
La page se met aussi à jour toute seule toutes les heures (tâche Windows « Bons Plans Canada - mise a jour »). Pour l'arrêter : ouvrez le « Planificateur de tâches » et supprimez cette tâche.
(Il faut Node.js. Mots-clés : categories.json. Sources : sources.json.)
Le site public (pour l'affiliation) est créé dans le dossier site/ à chaque mise à jour. L'adresse de contact se change dans bons-plans.js (textes CORPS_APROPOS et CORPS_CONFID).
Site en ligne : https://gcbsoh-boop.github.io/bons-plans/ (mis à jour toutes les heures par GitHub, même PC éteint).
« Ma liste » : écrivez un produit (ex. : télé 55) et la page vous dit s'il faut acheter maintenant ou attendre. La liste reste dans votre navigateur.
Les mois de rabais sont dans calendrier.json ; l'historique des prix est gardé dans historique.json (un an).
