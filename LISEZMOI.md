# Bons plans
1. Double-cliquez sur « Ouvrir les bons plans.bat ».
2. Attendez quelques secondes : la page s'ouvre toute seule.
3. Tapez un mot dans la case, ou cliquez sur une catégorie.
4. Cliquez sur une offre pour l'ouvrir. Pour mettre à jour, double-cliquez à nouveau.
(Il faut Node.js. Mots-clés : categories.json. Sources : sources.json.)
